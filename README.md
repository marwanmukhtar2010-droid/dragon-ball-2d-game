Dragon Ball 2D Fighting Game

A browser-based 2D fighting game experiment inspired by the visual language and gameplay concepts of Dragon Ball.

The project focuses on interactive combat, character selection, animation, responsive controls, and browser-based game development.

Features

- 2D fighting gameplay
- Character selection
- Match configuration
- Multiple game modes
- Adjustable AI difficulty
- Multiple battle arenas
- Character animations
- Combat and game-state systems
- Keyboard controls for desktop
- Touch controls for mobile devices
- Pause and restart functionality
- Responsive game interface

Technologies

- HTML5
- CSS3
- JavaScript
- Browser-based game technologies
- Responsive Web Design

Development Approach

This project was developed as an AI-assisted game development experiment.

AI development tools were used to explore aspects of the visual identity, interface design, implementation, and game-development workflow. The resulting project was assembled and refined as a browser-based interactive experience.

Learning Goals

The project was created to experiment with:

- JavaScript game development
- Interactive gameplay systems
- Character animation
- Game-state management
- Responsive control systems
- Mobile and desktop game interfaces
- UI/UX design for browser games
- AI-assisted software development

Project Status

Experimental and educational browser game project.

The project is primarily intended as a demonstration of frontend and interactive development techniques rather than a commercial game.
